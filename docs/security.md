# Public Repository Security

## This repository is public

Treat every committed file as public information.

## Never commit

- passwords, API keys, tokens, certificates, secrets
- financial account numbers or card numbers
- home address or other personal identifiers
- customer information or customer contacts
- customer code or proprietary implementation details
- emails or Slack messages
- confidential project details
- confidential company policy text
- malicious code or prohibited content

## Before committing

Ask:

1. Could this identify or expose a person?
2. Could this expose a customer or customer environment?
3. Could this expose proprietary implementation details?
4. Could this reveal credentials or secrets?
5. Would the content be appropriate on a public webpage?

If any answer is yes or uncertain, do not commit until the issue is resolved.
