# Review Checklist

## Content
- [ ] Source-backed
- [ ] Status assigned
- [ ] Uncertainty called out
- [ ] Central source index updated when appropriate

## Public safety
- [ ] No PII
- [ ] No financial account data
- [ ] No customer information
- [ ] No proprietary customer code
- [ ] No private emails or Slack content
- [ ] No confidential project details
- [ ] No secrets or credentials

## AI quality
- [ ] Ambiguity was surfaced rather than guessed
- [ ] Human review occurred where needed
- [ ] Handoff captured for substantial work
