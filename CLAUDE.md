# Claude Instructions

Use `AI.md` and `AGENTS.md` as the governing instructions.

Claude is the preferred assistant for coding and writing/presentation work in this repository. That preference does not override repository safety, source-quality, or ambiguity rules.

For substantial work:
1. Read the relevant project `context.md`.
2. Preserve the operational goal, audience, role/persona, constraints, negative constraints, source material, course corrections, and current state from the prior AI session.
3. Update the project artifacts rather than keeping important decisions only in chat.
4. Create or update `handoff.md` when the session materially changes project state.
