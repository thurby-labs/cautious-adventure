# Source Validation Skill

Use this when a claim will influence a decision or become durable repository knowledge.

## Validation sequence

1. Locate the underlying source.
2. Confirm the source actually supports the claim.
3. Check source authority and provenance.
4. Check publication/update date when relevant.
5. Look for scope limits, version limits, or population limits.
6. Check for corroboration when the claim is material.
7. Record the source and validation status.

## Statuses

- `VALIDATED`: directly supported by a strong source.
- `SUPPORTED`: supported, but source authority or scope is limited.
- `CONFLICTING`: credible sources disagree.
- `STALE`: previously useful, but no longer current.
- `UNVERIFIED`: source not yet checked.

Never convert `UNVERIFIED` into `VALIDATED` merely because multiple AI systems repeat the same claim.
