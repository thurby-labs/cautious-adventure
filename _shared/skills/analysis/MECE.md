# MECE Analysis Skill

## Purpose

Structure a problem into categories that are as mutually exclusive and collectively exhaustive as the available evidence permits.

## Method

1. Define the exact question.
2. Define the unit of analysis.
3. Choose one decomposition principle.
4. Create top-level categories.
5. Test overlap.
6. Test for material gaps.
7. Keep categories at comparable levels of abstraction.
8. Stop when additional decomposition no longer improves the decision.

## Quality check

For every category ask:

- Does it overlap another category?
- Is it actually part of the same question?
- Is it supported by the available evidence?
- Is the decomposition useful for the intended decision?

MECE is a structuring method, not proof that the underlying categories are objectively complete.
