# Hypothesis-Driven Analysis Skill

## Purpose

Move from a broad problem to testable explanations and evidence.

## Method

1. Define the problem and desired outcome.
2. State the initial hypothesis.
3. Identify observable implications.
4. Identify evidence that would support or weaken it.
5. Prioritize the highest-information tests.
6. Gather evidence.
7. Update the hypothesis.
8. Record the conclusion and remaining uncertainty.

## Rule

A hypothesis is a testable proposition, not a conclusion written in advance.

## Output

Use:

| Field | Content |
|---|---|
| Problem | What needs explanation or improvement |
| Hypothesis | Testable proposition |
| Evidence | Observations or sources |
| Result | Supported, weakened, or unresolved |
| Implication | What changes because of the result |
| Next test | Highest-value next evidence |
