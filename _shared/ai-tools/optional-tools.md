# Optional AI Tools

This file lists tools that may be useful but are deliberately outside the core routing model.

## Gemini

Gemini is not a required dependency for `cautious-adventure`. If a future Google-centered workflow makes it useful, add a specific use case and routing rule before adding it to the core tool matrix.

## Perplexity

Perplexity is already supported as an optional research-discovery tool. Workflows must remain usable without a paid plan. See [`perplexity.md`](perplexity.md).
