# Claude Profile

**Primary role in cautious-adventure:** substantial coding, long-form writing, repository reasoning, and artifact-oriented work.

## Best fit

- Implementing a multi-file coding change.
- Refactoring and debugging.
- Long-form technical or business writing.
- Working through a large body of project context.
- Producing self-contained artifacts that need iteration.

## Working pattern

1. Read repository instructions first.
2. Inspect the existing implementation before proposing changes.
3. Identify the smallest coherent change.
4. Implement and test.
5. Explain changed files and tradeoffs.
6. Update project documentation and handoff state.

## Projects and artifacts

Claude Projects provide a focused workspace with project knowledge and instructions. Claude Artifacts are designed for substantial, self-contained content that can be iterated on or reused.

## Do not use as a substitute for

- A repository source of truth.
- Direct source verification when a primary source is available.
- Human approval for decisions with material consequences.
