# ChatGPT Profile

**Primary role in `cautious-adventure`:** research, source synthesis, analysis, requirements, and general problem solving.

## Use ChatGPT for

- Research and source-backed synthesis.
- Requirements discovery and clarification.
- Document analysis.
- Decision framing and tradeoff analysis.
- Study guides and knowledge work.
- Research that needs a clear evidence trail.

## Adobe projects

For Adobe projects, ChatGPT should generally handle **research and requirements**, not duplicate the implementation that will be performed by GitHub Copilot.

Typical handoff:

`ChatGPT research → research.md / requirements.md → Claude architecture → Copilot implementation`

## Avoid duplicate work

Once research or analysis is complete, package the result into the repository artifact that the next tool needs. Do not ask another AI to redo the same analysis unless the purpose is explicit validation.
