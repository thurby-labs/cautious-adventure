# Perplexity Profile

**Status:** Optional secondary tool. The repository does not require a paid Perplexity plan.

**Primary role in `cautious-adventure`:** rapid web discovery and finding candidate sources before deeper synthesis in ChatGPT.

## Use Perplexity for

- Fast search-first exploration.
- Finding candidate sources and documentation.
- Spotting alternate terminology or relevant sources you may have missed.
- A quick second research trail when source discovery is the bottleneck.

## Do not use it as the default for

- Final source-backed synthesis.
- Repository implementation.
- Adobe project coding.
- Long-form document production.
- Decisions that require a carefully documented evidence trail without verifying the underlying sources.

## Free-tier rule

Design workflows so the **free tier is sufficient**. Do not assume access to paid-only models, higher search quotas, premium research modes, or premium file limits.

If a task exceeds the available free tier:

1. Continue with ChatGPT or manual web research.
2. Use the underlying primary sources directly.
3. Do not redesign the repository around a paid Perplexity feature.

## Research hygiene

Treat Perplexity results as discovery aids. Open and verify important claims against the original source before putting them into `research.md`, `source-index.md`, or a final deliverable.
