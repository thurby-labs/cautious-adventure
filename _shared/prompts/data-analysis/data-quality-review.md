# Data Quality Review

```text
Review the supplied dataset or table before analysis.

DATA:
[Attach or paste data]

Check:
- missing values;
- duplicate records;
- inconsistent categories;
- impossible or suspicious values;
- mixed units;
- date/time inconsistencies;
- outliers that may be data errors;
- ambiguous field definitions;
- leakage or target contamination if predictive modeling is involved.

For each issue provide:
- field/row reference;
- issue;
- evidence;
- likely impact;
- recommended treatment;
- whether the treatment changes the analysis.

Do not modify the data silently. Clearly distinguish observed problems from hypotheses about their cause.
```
