# Visual Brief for Image Generation

```text
Turn this idea into a production-ready visual brief.

IDEA:
[Describe idea]

Define:
- subject;
- setting;
- composition;
- camera/viewpoint if relevant;
- lighting;
- visual style;
- color direction;
- typography if any;
- aspect ratio;
- intended audience;
- required elements;
- elements to avoid.

Do not reference a living artist as the requested style. Describe visual characteristics instead.

Return:
1. Final image-generation prompt.
2. Negative constraints.
3. Suggested aspect ratio.
4. Two alternate compositions.
```
