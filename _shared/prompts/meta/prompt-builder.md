# Prompt Builder

Use this when a task is important enough to deserve a reusable prompt.

## Copy/paste prompt

```text
Help me turn the following request into a reusable prompt.

REQUEST:
[Paste the rough request]

First identify:
1. The actual objective.
2. The intended audience.
3. The required inputs.
4. The expected deliverable.
5. Hard constraints and negative constraints.
6. Source requirements.
7. Quality criteria.
8. What remains ambiguous.

If a requirement is materially ambiguous, ask me before finalizing the prompt.

Then produce:
- a reusable prompt;
- required inputs;
- expected output structure;
- validation checklist;
- one realistic example.

Do not add requirements merely to make the prompt look complete.
```

## When to use

Use this once a task is repeated or likely to be repeated. For a one-off task, write the task directly instead of creating prompt overhead.
