# Project Starter Prompt

Use this when starting a substantial project or POC.

```text
Help me start a project in the cautious-adventure repository.

PROJECT NAME:
[Name]

ROUGH GOAL:
[Goal]

KNOWN CONTEXT:
[Context]

Create a proposed project package containing:
- README.md
- context.md
- requirements.md
- decisions.md
- research.md
- next-steps.md
- handoff.md

Before finalizing the package:
1. Identify missing information.
2. Ask questions for anything materially ambiguous.
3. Do not invent audience, success criteria, data, architecture, or constraints.
4. Define a clear business case.
5. If AI is involved, define an evaluation approach and responsible-AI guardrails.
6. Assign an initial status: idea, active, paused, complete, or archived.

Return the proposed contents for review before treating the project as established.
```
