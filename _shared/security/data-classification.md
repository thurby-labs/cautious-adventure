# Data Classification for AI Work

Use this simple classification before sending information to an AI tool or committing it to `cautious-adventure`.

| Class | Meaning | Public repository? |
|---|---|---|
| PUBLIC | Safe for public release | Yes, after normal review |
| INTERNAL | Intended for an organization but not public | No |
| CONFIDENTIAL | Sensitive business or personal information | No |
| RESTRICTED | Highly sensitive or regulated information | No |
| PROHIBITED | Information explicitly excluded by repository rules | No |

## Stop rule

If classification is uncertain, do not commit or transfer the material until the appropriate human owner confirms it.

## Public-repository prohibited examples

- passwords, API keys, tokens, certificates;
- personal financial account/card information;
- home addresses and unnecessary PII;
- proprietary customer code or information;
- customer contacts, emails, Slack messages;
- confidential project details;
- private source material that has not been cleared for publication.
