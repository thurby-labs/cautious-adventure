# Public Repository Check

Run before committing a new file or publishing a significant change.

## Content check

- [ ] The content is intentionally public.
- [ ] No secrets or credentials are present.
- [ ] No personal financial information is present.
- [ ] No home address or unnecessary PII is present.
- [ ] No proprietary customer information is present.
- [ ] No customer contacts, emails, Slack messages, or confidential project details are present.
- [ ] No private source material has been copied without permission.

## Provenance check

- [ ] External material is attributed or linked where required.
- [ ] Licenses and reuse restrictions have been considered.
- [ ] Examples are clearly labeled when synthetic or generalized.

## AI check

- [ ] AI-generated claims have been reviewed.
- [ ] Important sources are preserved.
- [ ] Tool-specific instructions do not expose private context.

## Final question

**Would I be comfortable giving this exact file to an unknown person on the internet?**

If not, stop and revise it.
