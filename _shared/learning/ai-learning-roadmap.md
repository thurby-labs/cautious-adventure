# AI Learning Roadmap

This is a learning sequence, not a certification claim or a list of required products.

## Level 1: Reliable AI use

- Write clear objectives.
- Provide the right context.
- State constraints.
- Ask for explicit uncertainty.
- Verify important claims.
- Preserve sources.

## Level 2: Repeatable workflows

- Turn successful tasks into prompts.
- Turn repeated prompts into skills.
- Turn multi-step skills into recipes.
- Create handoffs between tools.

## Level 3: AI-assisted engineering

- Repository instructions.
- Tests and validation.
- Code review.
- Evaluation datasets.
- Failure analysis.
- Documentation and handoffs.

## Level 4: AI systems and POCs

- Retrieval and grounding.
- Evaluation frameworks.
- Responsible AI guardrails.
- Agentic workflows.
- Human approval points.
- Cost and operational considerations.

## Learning rule

When learning a new technique, capture one small working example in `personal/projects/poc/` if it is safe for this public repository.
