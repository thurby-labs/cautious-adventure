# Recipe: Research to Report

## Use when

You need a durable research artifact rather than an answer that lives only in chat.

## Steps

1. Start with `_shared/skills/research/SKILL.md`.
2. Use `_shared/prompts/research/research-plan.md` to establish the plan.
3. Gather primary and authoritative sources.
4. Validate material claims with `_shared/skills/research/source-validation.md`.
5. Write findings with clear evidence and uncertainty.
6. Add source links to the research file.
7. Add the most reusable sources to `docs/source-index.md` when appropriate.
8. Run the final deliverable review.

## Deliverable

A report that can stand on its own without the original conversation.
