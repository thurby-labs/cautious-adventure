# Recipe: Problem to Architecture

## Steps

1. Clarify the problem and desired outcome.
2. Capture requirements.
3. Capture constraints and assumptions.
4. Document the current state if relevant.
5. Define candidate solution boundaries.
6. Evaluate alternatives and tradeoffs.
7. Produce a solution outline.
8. Run the architecture review skill.
9. Record decisions.
10. Identify implementation next steps.

## Outputs

- problem statement;
- requirements;
- assumptions;
- architecture diagram or outline;
- tradeoffs;
- risks;
- decisions;
- next steps.
