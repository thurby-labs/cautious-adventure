# Recipe: Idea to POC

## Standard project artifacts

Create:

- `README.md`
- `context.md`
- `requirements.md`
- `decisions.md`
- `research.md`
- `next-steps.md`
- `handoff.md`

## Steps

1. Define the business problem.
2. State the hypothesis.
3. Define success criteria.
4. Identify required data and constraints.
5. Define an evaluation framework.
6. Build the smallest useful prototype.
7. Test against the evaluation framework.
8. Record results and limitations.
9. Decide whether to continue, pause, complete, or archive.

## Required POC qualities

Every POC needs a business case, data requirements, model/evaluation framework where AI is involved, and responsible-AI guardrails.
