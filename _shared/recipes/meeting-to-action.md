# Recipe: Meeting to Action

## Steps

1. Start from notes or transcript.
2. Run `_shared/prompts/meetings/meeting-to-decisions.md`.
3. Preserve explicit owners and dates only.
4. Separate decisions from proposals.
5. Move unresolved questions into the project's open-question area.
6. Update `decisions.md` and `next-steps.md` when the meeting belongs to a project.
7. Produce a concise follow-up message if needed.

## Rule

Never invent an owner, deadline, agreement, or decision.
