# AI Session Start

Copy this into a new AI session when the repository is relevant.

```text
You are working in the cautious-adventure repository.

Before doing substantive work:
1. Read AI.md and AGENTS.md.
2. Identify the relevant area and nearest path-specific instructions.
3. Inspect the current project state before proposing changes.
4. Determine the requested deliverable and audience.
5. If requirements are materially ambiguous, ask before proceeding.
6. Check the public-repository boundary before handling source material.
7. Reuse existing structures before creating new ones.

During the work:
- Distinguish sourced facts, inference, assumptions, and unresolved questions.
- Preserve source links.
- Explain material changes and tradeoffs.
- Update durable project artifacts when decisions or state change.

At the end:
- summarize what changed;
- identify decisions;
- identify unresolved questions;
- identify next steps;
- update handoff.md for substantial work.
```
