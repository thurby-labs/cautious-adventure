# Final Deliverable Review

Use this before considering a substantial AI-assisted artifact complete.

## Requirements

- [ ] The stated objective is met.
- [ ] All explicit requirements are addressed.
- [ ] Ambiguities were resolved rather than guessed.

## Evidence

- [ ] Sources are included where needed.
- [ ] Material claims are validated.
- [ ] Assumptions are visible.
- [ ] Uncertainty is visible.

## Quality

- [ ] Structure matches the audience.
- [ ] Terminology is consistent.
- [ ] No unnecessary duplication.
- [ ] Examples are clearly identified.

## Safety

- [ ] No secrets or credentials.
- [ ] No personal financial information.
- [ ] No home address or unnecessary PII.
- [ ] No proprietary customer information.
- [ ] No confidential project details.

## Handoff

- [ ] Current state is recorded.
- [ ] Decisions are recorded.
- [ ] Open questions are recorded.
- [ ] Next steps are recorded.
- [ ] `handoff.md` is current when the work is substantial.
