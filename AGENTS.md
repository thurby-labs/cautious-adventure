# Agent Instructions for cautious-adventure

Read `AI.md` first.

## Before changing files

1. Identify whether the task belongs to `_shared`, `personal`, or `adobe`.
2. Read the nearest `AI.md` or directory-specific instructions.
3. Inspect the existing project context before creating new structure.
4. If the request is ambiguous, ask before changing files.
5. Check the public-repository safety boundary.

## During work

- Prefer existing files and conventions over creating duplicates.
- Propose simpler structures when a request would add unnecessary directories.
- Keep source provenance with research.
- Make decisions explicit in `decisions.md`.
- Keep `handoff.md` current at the end of substantial sessions.

## Before completion

- Run repository checks where available.
- Review the diff for secrets, PII, proprietary content, and accidental customer information.
- Summarize what changed and what remains unresolved.
